# Задание 3 — Создание векторного индекса базы знаний

## Краткое описание

Для индексации использована модель
[Qwen/Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B)
через Sentence-Transformers, выбранная в задании 1.
Размер эмбеддинга — 1024. База знаний — 30 документов
из `task-2/knowledge_base/`.

Документы разбиты с помощью `RecursiveCharacterTextSplitter` из LangChain.
Размер чанков — 100–300 слов. Короткие фрагменты дополнены соседним текстом
с перекрытием. Для каждого чанка сохранены текст, заголовок, путь к источнику,
ID, номер фрагмента, строки и символьные позиции в документе.

Эмбеддинги рассчитаны на NVIDIA GeForce RTX 5070 Ti и сохранены в FAISS
`IndexFlatIP`. Индекс работает на CPU. Запрос кодируется той же версией
эмбеддинг-модели; поиск возвращает три ближайших чанка по косинусной близости
нормализованных векторов.

## Запуск

Команды выполняются в PowerShell из корня проекта `sprint-7`.

Установка зависимостей для запуска на NVIDIA GPU:

```powershell
& .\.venv\Scripts\python.exe -m pip install -r .\task-3\requirements.txt
& .\.venv\Scripts\python.exe -m pip install "torch==2.13.0+cu130" --index-url https://download.pytorch.org/whl/cu130
```

Построение индекса:

```powershell
& .\.venv\Scripts\python.exe .\task-3\build_index.py --device cuda
```

Для повторной сборки удалите папку `task-3/index/`.

Три примера поиска с сохранением запросов и найденных чанков:

```powershell
& .\.venv\Scripts\python.exe .\task-3\search.py --examples --device cuda
```

## Результат

Создан индекс из **44 чанков** по 30 документам.
Генерация эмбеддингов заняла **1,3 секунды**, полное время сборки
с моделью из локального кэша — **11,8 секунды**.

Выполнены три пробных запроса. При ручной проверке для первых двух
нужные сведения найдены в первом результате, для третьего полезная
информация содержится в двух фрагментах из трёх.

- `index/faiss.index` — созданный векторный индекс.
- `build_index.py` — код создания и сохранения индекса.
- `search_examples.json` — три поисковых запроса и найденные чанки.
- `index/chunks.jsonl` — тексты чанков и метаданные.
- `index/report.json` — параметры и статистика построения индекса.
