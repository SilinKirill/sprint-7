# Навигационный компьютер

Устройство рассчитывает точку назначения, безопасный маршрут и необходимое количество пространственных переходов. На небольших кораблях объём хранимых маршрутов может быть ограничен. Крупные системы способны содержать координаты значительно большего числа пунктов назначения. Существуют переносные исполнения. Основная задача устройства — подготовка точных навигационных данных для перехода корабля между удалёнными областями пространства.
