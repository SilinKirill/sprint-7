# Генератор гравитационной тени

Устройство создаёт разрушительную гравитационную волну. Питающий реактор одновременно существует в обычном пространстве и другом измерении, получая энергию из гравитационного поля планеты. Область действия ограничена её орбитой. Воздействие способно уничтожать орбитальные объекты и наносить тяжёлые повреждения самой планете. Эффективность установки связана с особенностями гравитационной обстановки в месте размещения.
