# Восстановительный состав «КР-AFE84C22»

Медицинское средство для заживления ран и восстановления тканей без образования шрамов. Применяется в повязках, инъекциях, мазях и при погружении пациента в резервуар с раствором. Имеет выраженный сладковатый запах, который может сохраняться после лечения несколько недель. Резервуары бывают стационарными и переносными. В переносном варианте пациент располагается лёжа; раствор может использоваться повторно после фильтрации.
