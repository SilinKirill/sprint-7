# Реактивный ускоритель «КР-AE102642»

Двигатель для движения корабля на досветовых скоростях. Энергия термоядерного реактора разгоняет поток частиц, создающий реактивную тягу. Работа сопровождается образованием радиоактивных побочных продуктов. Ионизированные частицы также могут воздействовать на электронику. По этим причинам такие двигатели обычно включают на орбите, а для полётов в атмосфере используют другие двигательные системы.
