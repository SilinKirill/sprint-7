# Информационный планшет «КР-8D9342D3»

Небольшое устройство для хранения текстов, изображений и объёмных визуальных данных. Может выполнять функции записной книжки, планировщика, калькулятора и графического планшета. Некоторые модели загружают информацию из крупных сетей. Типичная комплектация включает цветной сенсорный экран, звуковые датчики, разъём для наушников и источник питания. Дополнительные материалы могут поставляться на сменных картах памяти.
