# Тяжёлый импульсный излучатель «КР-E3A798C6»

Крупное энергетическое орудие, обычно устанавливаемое во вращающейся турели на корабле, станции или наземной позиции. Использует высокоёмкие конденсаторы для накопления энергии и её быстрой отдачи при выстреле. Такой запас обеспечивает более мощный импульс по сравнению с обычными корабельными энергетическими орудиями. Поражающий пучок дополнительно уплотняется электромагнитным полем.
