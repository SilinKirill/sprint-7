# Задание 2 — Подготовка базы знаний

Предметная область — технические объекты русской Вукипедии.
Выбрана 31 страница об устройствах, материалах и оборудовании.
Ссылки и версии страниц указаны в `sources.json`.
Авторы источников — участники Вукипедии.

## Подготовка

Страницы скачаны через MediaWiki API. Для каждой подготовлена
короткая выжимка: назначение, свойства и ограничения.
Удалены сюжетные сведения, имена персонажей, названия мест
и производителей. Один документ соответствует одной сущности.

Исходные названия оставлены только в заголовках.
Скрипт `build.py` заменяет их на обозначения вида
«Тип изделия КР-код». Случайные коды создаются локально,
текст описаний сохраняется.

## Файлы

- `knowledge_base/` — 31 итоговый Markdown-документ.
- `terms_map.json` — словарь «исходное название → новое».
- `prepared/` — подготовленные описания до замены.
- `sources.json` — список источников.
- `sources_cache.json.gz` — сжатый кэш исходных страниц.
- `fetch.py` — скачивание источников.
- `build.py` — проверка и замена названий.
- `requirements.txt` — зависимости для скачивания.

## Запуск

Создание базы из PowerShell:

```powershell
& 'D:\GitHub\sprint-7\.venv\Scripts\python.exe' 'D:\GitHub\sprint-7\task-2\build.py'
```

Существующий результат не перезаписывается.
Проверка подготовленных материалов без создания базы:

```powershell
& 'D:\GitHub\sprint-7\.venv\Scripts\python.exe' 'D:\GitHub\sprint-7\task-2\build.py' --check
```

## Использование

Для RAG используется только `task-2/knowledge_base/`.
Словарь и исходные материалы в индекс не включаются.

Переименование не гарантирует неузнаваемость источника.
Работу RAG проверяем сравнением ответов с контекстом из базы
и без него.
