# Задание 2 — Подготовка базы знаний

Источник — англоязычная Wookieepedia, вселенная Star Wars.
Выбрано 30 статей Canon и Legends о дроидах и моделях аналитических
дроидов, связанных общими персонажами, местами и событиями.

## Подготовка и замена

Страницы скачаны через MediaWiki API. Удалены карточки, навигация,
сноски и служебные разделы. Основной текст и внутримировые цитаты
сохранены без сокращения и пересказа.

Исходный корпус содержит 8542 слова: по 163–398 слов на документ.
Один файл соответствует одной сущности.

По текстам составлен список из 288 сущностей и 379 вариантов
упоминаний. Названия генерируются локально через `random` с seed 7,
с учётом типа сущности. Некоторые технологии получают фиксированные
эквиваленты.

Замена выполняется по общему словарю: длинные совпадения раньше
коротких, с учётом псевдонимов, границ слов и притяжательных форм.
Существующий словарь защищён от перезаписи.

## Файлы

- `knowledge_base/` — 30 итоговых документов.
- `terms_map.json` — словарь «исходное → вымышленное».
- `prepared/` — очищенные тексты до замены.
- `terms_source.json` — исходные сущности и варианты упоминаний.
- `sources.json` — ссылки, версии страниц и история правок.
- `sources_cache.json.gz` — кэш исходного HTML.
- `fetch.py` — скачивание и очистка.
- `generate_terms.py` — генерация словаря.
- `build.py` — сборка и проверка базы.
- `requirements.txt` — зависимости.

## Запуск

Команды выполняются в PowerShell из корня проекта `sprint-7`.

При необходимости установить зависимости и повторно подготовить исходники:

```powershell
& .\.venv\Scripts\python.exe -m pip install -r .\task-2\requirements.txt
& .\.venv\Scripts\python.exe .\task-2\fetch.py
```

При наличии кэша подготовка работает без сети. Без кэша скачиваются
зафиксированные версии страниц.

Создать словарь, собрать базу и проверить результат:

```powershell
& .\.venv\Scripts\python.exe .\task-2\generate_terms.py
& .\.venv\Scripts\python.exe .\task-2\build.py
& .\.venv\Scripts\python.exe .\task-2\build.py --check
```

База уже создана, поэтому для её проверки достаточно последней команды.
Генерация нужна только при отсутствии словаря. Повторная сборка
использует сохранённый словарь и проверяет существующий результат,
не перезаписывая его. Сборка и проверка не требуют сети.

## Результат

Созданы 30 документов, выполнено 1570 замен. Проверка подтвердила
отсутствие перечисленных исходных терминов, замены внутри каждого
документа и соответствие результата подготовленным текстам и словарю.

Для RAG используется только `task-2/knowledge_base/`.
Словарь, кэш и подготовленные исходники в индекс не включаются.

Переименование не гарантирует неузнаваемость сюжета. Работу RAG
проверяем сравнением ответов с извлечённым контекстом и без него.
